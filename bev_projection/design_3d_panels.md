# 三模型交互式 3D 面板 · 设计文档（2026-10-27）

## 意图

延续 LSS 节的交互式 3D 改造（见 `design_3d_frustum.md`），为 BEVFormer、TPVFormer、VoxFormer 三节各建一个同模式的交互面板，并在各家流水线图中加核心步骤标识。全篇主线不变：**可学习参数 vs 固定几何**；两态语义统一为"熄灭＝固定几何/代价，点亮＝可学习机制生效"（用户已确认，含各自聚焦对象）。

## 目标

1. **位置与重排**：每节 ① 机制总览的机制图按 LSS 先例拆分——现有 A 分区保留，插入新 B 交互面板（`.panel` 同款结构：标题/控制行/canvas/小结），原 B 分区顺延为 C（标题与全文引用一并清扫）。
2. **共享代码骨架**：全文件仍**恰好一个 `<script>`**——重构现有 `frustum3d-script` 为"公共库（透视投影/画家排序/拖拽旋转/缩放滑杆/两态按钮/联动拖拽/只读 `__state` 测试钩子）+ 四个面板 IIFE"，LSS 面板行为必须等价保持（浏览器回归验证后其余三家才动工）。
3. **BEVFormer（拉）**：场景＝BEV 平面网格（200×200 抽样）＋相机示意（建议 2 台命中聚焦＋其余灰影）；聚焦一个 query 格：pillar 的 4 个 z 锚 {−4.5, −2.167, 0.167, 2.5} m 与 lidar2img 投影线为**蓝虚线固定几何**。熄灭＝只有固定锚点与投影；点亮＝query 格与 bev_embedding 亮橙、每锚 deformable **采样点簇**围绕参考点散布（可学习偏移，示意）。联动＝在 BEV 平面拖动 query 格，投影线与命中相机实时变化（投影落入相机视野的相机点亮，hit 语义）。小结数字白名单：200×200＝40000、4 z 锚四值、每命中相机 256 采样位。
4. **TPVFormer（压缩）**：场景＝淡灰稠密体素体积（200×200×16 抽样呈现，"640000 槽"的代价感）＋三正交平面（hw 200×200、zh/wz 16×200）。熄灭＝稠密体素；点亮＝三平面亮橙（三张 query 表，46400＝640000 的 7.25%）、体素变淡，一个**选中体素**显示到三平面的双线性采样连线与"等权求和（零参数）"标注。联动＝在三平面包围盒内拖动选中体素，三平面采样点跟随。白名单：三平面形状、46400、7.25%、等权求和零参数。
5. **VoxFormer（门控）**：场景＝128×128×16（@0.4 m）query 体网格全槽淡灰。熄灭＝全槽灰（262144 槽无激活）；点亮＝**门控生效**——近相机侧可见带亮橙（示意 N_p，被拉取体素到相机少量拉取线），**其余全部槽位淡橙**（stage-2 可学习 mask token 广播补全，N_p→262144，忠实底稿 step 11；非"仍灰"）；联动＝"门控程度"滑杆（加宽亮带，淡橙集恒为其补集）。白名单：128×128×16、262144、0.4 m。
6. **流程图核心步骤标识**（仿"Lift＝2D→3D"：框线加粗＋框内加粗标题，不浮框、不压线；**放在语义框实际所在分区**——BEVFormer 与 VoxFormer 的目标框在各自 A 区（A 不拆不重排，仅框内标识），TPVFormer 的在 C 区）：
   - BEVFormer A 区 encoder 总览的 SCA 步骤框：标题行"拉＝3D→2D"；
   - TPVFormer C 区流水线的三平面/ICA 相关框：标题行"压缩：640000→46400"；
   - VoxFormer A 区 Stage-1 的深度提议（门控）框：标题行"门控：谁有 query"。
7. **每面板标配**：拖拽旋转＋缩放滑杆（沿用 40–160）＋两态按钮＋联动＋小结文字（数字白名单、示意标注、aria-label）。

## 非目标

- 不做时序（BEVFormer temporal）、不做真实权重/真实标定投影（相机与投影全部示意并标注"示意"）；
- 不改 LSS 面板行为（公共库重构仅限等价重构）；
- 不引入第五家、不做移动端适配。

## 反目标（做错即失败）

- `<script>` 数量超过 1；外部资源、禁词（qwen/uvtr/本仓库/analysis/）、CJK 邻接半角逗号任一非零；
- 示意数据冒充真实输出；
- 破坏各节现有 A/C 面板、统一图例与既有审计；LSS 面板回归失败。

## 约束

- 沿用 `design_3d_frustum.md` 全部约束（离线自包含、排版、图例语义：橙=可学习、蓝虚线=固定、灰白=数据、箭头=流）；
- 每面板单帧图元量级 ≤1 万（点/线合计），重绘目标 <10ms；
- 浏览器实测交付（http 服务 + 程序化像素/状态断言 + 截图视觉抽检）。

## 方案选择（已确认）

| 决策点 | 备选 | 选定 |
| --- | --- | --- |
| 两态语义与聚焦对象 | — | 用户 2026-10-27 确认（BEV 单 query 拉取／TPV 三平面压缩对比／Vox 门控点亮） |
| 代码组织 | 每家独立 script（违反单 script）／单 script 多 IIFE＋公共库／外部 js（违反离线） | 单 script＋公共库 |
| VoxFormer 联动 | 拖动相机朝向改变可见集（视角耦合不稳）／门控程度滑杆 | 门控程度滑杆 |

## 留给建造者

各面板相机初始角、抽样密度与颜色微调；BEVFormer 相机示意台数呈现（2 台聚焦＋灰影其余）；TPVFormer 选中体素初始位置；门控滑杆范围/默认值；C 面板标识的具体框选与行高适配。

## 建造顺序与验收

BEVFormer → TPVFormer → VoxFormer 逐家交付；每家完成即浏览器验证（两态像素断言、联动状态断言、拖拽/缩放、零报错）并提交；三家完成后做一次全篇回归（四面板同页共存、script=1、四项 grep、锚点与图例）。
