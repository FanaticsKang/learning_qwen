五条 2D→3D 投影机制＋一条工程实现：可学习参数与固定几何的分工 LSS · UVTR · BEVFormer · TPVFormer · VoxFormer · Qwen-Drive 实现

③ 2D-3D 关系

LSS 对"2D 特征如何进入 3D"的回答可归纳为四点：

  • 推/拉方向：推（push）。LSS 从 2D 图像侧出发，把每像素特征沿固定视锥射线"抬"到 3D（lift），再以纯 scatter 落进 BEV 网格（splat）；不存在 3D→2D 的采样/拉取路径，也没有任何 cross-attention。
  • 深度：显式分布、隐式监督。每个像素显式输出 41 维离散深度分布 α（softmaxsrc/models.py:48-49），格中心固定（4.0–44.0 m）；但 α 没有深度标签，仅由 BEV 任务损失端到端回传（论文 §3.1 称 latent depth，§5.1 frozen-encoder 消融证明其学到了有效深度）。两个极端可作对照：one-hot α 退化为 pseudo-lidar，均匀 α 退化为 OFT 式全程铺展。
  • 几何与学习的分工：可学习参数全部在投影桥两端。2D 侧（EfficientNet-B0 + up1 + depthnet）负责"什么内容、放在多深"，BEV 侧是 resnet18 式编码器；中间的投影核（视锥分箱、K/E 反投影、体素 scatter 求和）零参数、纯固定几何——"学习决定特征与深度权重，几何决定落点"。
  • query 有无：无 query。不存在可学习的 3D query / BEV embedding / position embedding；3D 位置全部来自固定视锥网格点（每相机 41×8×22=7216 个），BEV 格内容由落入该 pillar 的点求和得到src/models.py:236-240。这也是 LSS 与 BEVFormer（可学习 BEV query 拉取）对比时最根本的形态差异。

③ 2D-3D 关系

UVTR 对"2D 特征如何进入 3D"的回答可归纳为四点：

  • 推/拉方向：推家族的 3D 落点（加权语义），gather 式实现。UVTR 与 LSS 共享同一合成语义——"显式离散深度分布 × 图像特征"决定 3D 内容（论文 Eq.(2) 即 LSS Eq.(1) 的逐采样点形式models/utils/uni3d_viewtrans.py:218-222）；但实现路径相反：LSS 在 2D 侧枚举视锥点再 scatter 落格，UVTR 在 3D 侧枚举固定体素格点、经 lidar2img 投到 2D（3D→2D 定址），grid_sample 拉取特征与深度概率后加权求和（2D→3D 聚合）。聚合权重是显式 64 档深度概率而非 attention 偏移——这是它与 BEVFormer 式"拉"的本质区别；落点是 3D 体素格 5 层、保留高度不塌缩（论文 §3.1 "preserve the 3D voxel space without collapsing in Z axis" p.4）——这是它与 LSS"拍扁 2D"的本质区别。
  • 深度：显式分布、无监督。每相机每尺度各预测一份 64 档 softmax 深度分布（0–64 m、1 m/档uvtr_camera_base.py:62），无任何深度标签与深度损失（论文 §3.1 p.4 明示 "D_I is predicted without supervision"；代码侧检测头只有 Focal＋L1、数据管线不产深度 GTuvtr_camera_base.py:133-141uvtr_camera_base.py:197-211）；深度仅作为乘性权重由检测损失端到端回传——"显式分布、隐式（下游）监督"与 LSS 完全同构，BEVDepth 式 LiDAR 深度监督在 UVTR 中不存在。
  • 几何与学习的分工：桥零参数——"学习给内容与概率、几何给格点与定址"。固定几何决定"落点骨架"（linspace 体素格 128×128×5uvtr_camera_base.py:12,15-19、lidar2img 投影、hit 掩码、64 m 深度截断、加权求和）；学习决定"特征与深度概率"（2D 侧）与"落格后如何混合邻域、如何被 query 消费"（3D 侧 Conv3d 编码器＋decoder）。即与 LSS 同构、与 BEVFormer（桥上有 offsets/weights 学习量）相对。
  • query 有无及形态：桥上无 query，桥外有 900 object query。体素格点是 linspace 固定网格，不存在 BEVFormer 式 bev_embedding 参数表——体素内容是"被填充物"而非"主动查询者"；900 个 nn.Embedding(900,512) object query 在桥外 decoder 中以可学习参考点从体素体拉取特征models/dense_heads/uvtr_head.py:117-119models/utils/uni3d_detr.py:270-320。全篇对比中：UVTR＝固定 3D 格＋显式深度加权（推家族 3D 落点），与 LSS（固定 2D 视锥推＋pillar 塌缩）成第一组对照；与第五节 VoxFormer（稀疏 voxel query 门控）成一语对照——UVTR 稠密采样满格、VoxFormer 稀疏挑选。

BEVFormer 对"2D 特征如何进入 3D"的回答可归纳为四点：

③ 2D-3D 关系

VoxFormer 对"2D 特征如何进入 3D"的回答可归纳为五点：

  • 推/拉方向：拉为主、推在门口。在线主体是拉（pull）——3D voxel query 以自身格心经固定 lidar2img 投到图像、在命中相机上 deformable 采样"拉"取特征（与 BEVFormer/TPVFormer 同族，均为 BEVFormer 式 MSDA 血统modules/deformable_cross_attention.py:159-168）；但进入在线模型之前有一次决定性的"推"（push）——像素深度经 Eq.1 反投影成伪点云、光线投射成占用、QPN 修正后形成 proposal 掩码，2D 深度决定哪些 3D voxel 有资格成为 query（论文 §3.2 "2D features correspond to visible and occupied voxels"）。即：深度不参与在线特征提取，只做深度门控稀疏化——五家中唯一由深度显式决定 query 集合的模型。
  • 深度：显式、离线、无分箱。深度由外部立体模型 MSNet3D 一次性给出（可学习但外部冻结preprocess/image2depth.sh:6-8），连续值→离散占据，不存在 LSS 式 per-pixel 深度分布、也没有 TPVFormer 式沿射线多深度假设枚举（每查询 4/32/32 锚点）；在线注意力里每个 voxel 只有 1 个参考点（格心投影dense_heads/voxformer_head.py:208-214），深度不确定性被前置到 QPN 掩码里消化。代价即论文 Limitation：远距离深度不可靠→远距性能受限（§4.2.4 p.8）。
  • 几何与学习的分工：几何定"骨架"，学习定"内容与稀疏性"。固定几何——0.2/0.4 m 双层网格、格心锚点、lidar2img、hit 判定modules/encoder.py:105-144、命中相机均值、×2 三线性上采样utils/header.py:27；学习——query 嵌入表内容（262144×128）、N_p 的大小与分布（QPN，逐帧数据相关detectors/lmscnet.py:304-305）、采样偏移与权重（DCA 3 层＋DSA 2 层）、mask token、两侧主干。五家中 VoxFormer 独有：稀疏化本身是可学习的（LSS 稠密 splat、BEVFormer/TPVFormer 全网格 query）。
  • query 有无及形态：有，全网格表＋逐帧稀疏激活。N_q=262,144 条 3D 网格形可学习参数（论文 §3.3 "3D-grid-shaped learnable parameters"dense_heads/voxformer_head.py:53），每帧仅 N_p（QPN 输出，数据相关）参与 DCA——论文 Table 4（p.8）：100% dense 消融 IoU 34.6 vs occupancy 44.0、显存 18.5 G vs 14.6 G，稀疏既省显存又涨点；stage-2 用 mask token 把其余 voxel 补齐后经 DSA 稠密化（MAE 式 sparse-to-dense，论文 Fig.2 "Mask Token"＋"Updated Queries"dense_heads/voxformer_head.py:110-113）。对比：BEVFormer 40000 条 BEV 网格全激活、TPVFormer 46400 条三平面全激活、LSS 无 query。
  • 体间交互（BEVFormer 没有的）。DSA 是 voxel↔voxel 的 deformable 自注意力（3D 侧自注意力，论文 Eq.5；vanilla 实现在 512×512 展平索引面上采样modules/encoder.py:189-195）；BEVFormer 的 self-attn 在 BEV 平面＋时序，TPVFormer 的在平面间（CVHA）。VoxFormer 无时序 self-attn——T 变体的时序＝把历史帧当"更多相机"进 DCA（_temporal_=[-12,-9,-6,-3]、num_cams=5voxformer-T.py:18-19）。
