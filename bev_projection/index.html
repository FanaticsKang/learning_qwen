四种 2D→3D 投影机制：可学习参数与固定几何的分工 LSS · BEVFormer · TPVFormer · VoxFormer

多相机 3D 感知的第一步，是把 2D 图像特征"放进"3D 空间——LSS、BEVFormer、TPVFormer、VoxFormer 四条路线给出了四种截然不同的答案。本笔记用一组统一的问题逐个拆解：每条路线里，哪些几何由相机标定与深度/空间离散化一次性固定、不参与训练；哪些参数可学习、长在 2D 侧还是 3D 侧、以什么形态存在（深度分布、采样权重、query 嵌入、深度提议、mask token）。全文机制图共用一套视觉编码：橙色实线块表示可学习参数载体，蓝色虚线加斜纹块表示固定几何（见图例）；所有具体数字以各家开源代码的 nuScenes 配置为准，仓库地址与 commit hash 见页脚。
