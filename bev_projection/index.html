③ 2D-3D 关系

LSS 对"2D 特征如何进入 3D"的回答可归纳为四点：

  • 推/拉方向：推（push）。LSS 从 2D 图像侧出发，把每像素特征沿固定视锥射线"抬"到 3D（lift），再以纯 scatter 落进 BEV 网格（splat）；不存在 3D→2D 的采样/拉取路径，也没有任何 cross-attention。
  • 深度：显式分布、隐式监督。每个像素显式输出 41 维离散深度分布 α（softmaxsrc/models.py:48-49），格中心固定（4.0–44.0 m）；但 α 没有深度标签，仅由 BEV 任务损失端到端回传（论文 §3.1 称 latent depth，§5.1 frozen-encoder 消融证明其学到了有效深度）。两个极端可作对照：one-hot α 退化为 pseudo-lidar，均匀 α 退化为 OFT 式全程铺展。
  • 几何与学习的分工：可学习参数全部在投影桥两端。2D 侧（EfficientNet-B0 + up1 + depthnet）负责"什么内容、放在多深"，BEV 侧是 resnet18 式编码器；中间的投影核（视锥分箱、K/E 反投影、体素 scatter 求和）零参数、纯固定几何——"学习决定特征与深度权重，几何决定落点"。
  • query 有无：无 query。不存在可学习的 3D query / BEV embedding / position embedding；3D 位置全部来自固定视锥网格点（每相机 41×8×22=7216 个），BEV 格内容由落入该 pillar 的点求和得到src/models.py:236-240。这也是 LSS 与 BEVFormer（可学习 BEV query 拉取）对比时最根本的形态差异。

③ 2D-3D 关系

BEVFormer 对"2D 特征如何进入 3D"的回答可归纳为四点：

  • 推/拉方向：拉（pull）。主动方是 3D 侧的可学习 BEV query：先把每格 query 抬成 pillar、取 4 个固定 3D 参考点modules/encoder.py:46-71，经 lidar2img 投到 2Dmodules/encoder.py:95-136，再从命中相机的多尺度特征上"拉取"邻域特征（deformable 采样modules/spatial_cross_attention.py:134-172）。与 LSS（2D 侧推、scatter 落格）方向相反——投影方向本身是 3D→2D 定锚，特征流是 2D→3D 聚合。
  • 深度：隐式、无深度分布。不预测任何 per-pixel 深度（对比 LSS 的 41 维 α），无深度监督、无深度输出头；深度不确定性由 4 个固定 z 锚点离散枚举modules/encoder.py:62-63，由 attention 权重隐式加权modules/spatial_cross_attention.py:340-343——学习量只在采样偏移与权重上修正锚点邻域。
  • 几何与学习的分工："几何给锚点、学习给偏移"。固定几何决定候选落点——BEV 网格 200×200@0.512 mdense_heads/bevformer_head.py:61-62、z 锚点 {−4.5, −2.167, 0.167, 2.5} mmodules/encoder.py:62-63、lidar2img 投影与 hit 掩码modules/encoder.py:122-138、四层尺度归一化modules/spatial_cross_attention.py:357-363；学习决定"query 内容"（bev_embedding 40000×256）与"采多远、权重多少"（SCA sampling_offsets/attention_weights）。
  • query 有无及形态：有，且是网格形嵌入表。BEV query 是一张 (40000, 256) 的可学习嵌入表，逐格与 BEV 平面一一对应（论文 §3.2 "grid-shaped learnable parameters"dense_heads/bevformer_head.py:104-105），另有 (900, 512) 的 object query 供 decoder 用（桥之外dense_heads/bevformer_head.py:106-107）。这与 LSS 的"无 query、固定视锥点"构成四模型对比中的两极。

③ 2D-3D 关系

TPVFormer 对"2D 特征如何进入 3D"的回答可归纳为五点：

  • 推/拉方向：拉（pull）。主动方是 3D 侧的三组可学习平面 query：每个平面查询沿本平面正交轴取固定锚点射线（hw 4 点沿 Z、zh/wz 32 点沿 X/Ytpvformer10/modules/encoder.py:36-47tpvformer10/modules/encoder.py:124-148），经 lidar2img 投到 6 相机，从命中相机的多尺度特征上"拉取"锚点邻域特征（deformable 采样tpvformer10/modules/image_cross_attention.py:104-164）。与 BEVFormer 同为拉取式；差异在于锚点射线不在同一根 Z 轴上，而分散到三根正交轴。
  • 深度：隐式、无深度分布。不预测 per-pixel 深度（对比 LSS 的 41 维 α），无深度监督、无深度输出头；深度不确定性由每查询的锚点射线离散枚举（hw 沿 Z 4 档、zh/wz 沿水平轴 32 档），由 attention 权重隐式加权。
  • 几何与学习的分工：几何给"候选落点"，学习给"query 内容与采样幅度"。固定几何决定候选落点——三平面网格（0.512/0.5 m 格tpv_lidarseg.py:20-22）、正交轴锚点射线（4/32/32tpvformer10/modules/encoder.py:36-47）、跨视图 16 锚网格tpvformer10/modules/encoder.py:49-51、lidar2img 投影与 hit 掩码tpvformer10/modules/encoder.py:167-220、聚合阶段的投影＋双线性＋求和tpvformer10/tpv_aggregator.py:69-84；学习决定"query 内容"（三张嵌入表 46400×128）与"采多远、权重多少"（ICA/CVHA 的 offsets 与 weights）。特别的：平面之间的学习权重存在于 CVHA 的层级门控（attention_weights 第 33 个输出在 3 平面间 softmaxtpvformer10/modules/cross_view_hybrid_attention.py:123-127），而聚合阶段三平面是等权求和、无学习权重tpvformer10/tpv_aggregator.py:83-84（与论文 Eq.5 一致）。
  • query 有无及形态：有，且是三张平面嵌入表。TPV query＝(40000,128)＋(3200,128)＋(3200,128) 共 46400 条，逐格与三平面对应（论文 §3.2 "initialize TPV queries as learnable parameters"，且 TPV queries 与 TPV planes 指同一组特征向量、同物异名tpvformer10/tpv_head.py:53-55）。对比：BEVFormer 单表 40000 条（仅 BEV），LSS 无 query；TPVFormer 用 7.25% 于稠密 voxel 的 query 预算（46400 vs 640000）覆盖全 3D 空间——体表征靠"广播＋求和"零参数重建，任意分辨率可查（论文 Fig.6）。
  • 三平面交互（BEVFormer 没有的）。CVHA 让三平面 query 互为 key/value（跨平面 deformable 自注意力），是"3D 侧自注意力"tpvformer10/modules/cross_view_hybrid_attention.py:36-50；BEVFormer 的 self-attn 是 BEV 平面内＋时序，TPVFormer 无时序（单帧模型）。

③ 2D-3D 关系

VoxFormer 对"2D 特征如何进入 3D"的回答可归纳为五点：

  • 推/拉方向：拉为主、推在门口。在线主体是拉（pull）——3D voxel query 以自身格心经固定 lidar2img 投到图像、在命中相机上 deformable 采样"拉"取特征（与 BEVFormer/TPVFormer 同族，均为 BEVFormer 式 MSDA 血统modules/deformable_cross_attention.py:159-168）；但进入在线模型之前有一次决定性的"推"（push）——像素深度经 Eq.1 反投影成伪点云、光线投射成占用、QPN 修正后形成 proposal 掩码，2D 深度决定哪些 3D voxel 有资格成为 query（论文 §3.2 "2D features correspond to visible and occupied voxels"）。即：深度不参与在线特征提取，只做深度门控稀疏化——四家中唯一由深度显式决定 query 集合的模型。
  • 深度：显式、离线、无分箱。深度由外部立体模型 MSNet3D 一次性给出（可学习但外部冻结preprocess/image2depth.sh:6-8），连续值→离散占据，不存在 LSS 式 per-pixel 深度分布、也没有 TPVFormer 式沿射线多深度假设枚举（每查询 4/32/32 锚点）；在线注意力里每个 voxel 只有 1 个参考点（格心投影dense_heads/voxformer_head.py:208-214），深度不确定性被前置到 QPN 掩码里消化。代价即论文 Limitation：远距离深度不可靠→远距性能受限（§4.2.4 p.8）。
  • 几何与学习的分工：几何定"骨架"，学习定"内容与稀疏性"。固定几何——0.2/0.4 m 双层网格、格心锚点、lidar2img、hit 判定modules/encoder.py:105-144、命中相机均值、×2 三线性上采样utils/header.py:27；学习——query 嵌入表内容（262144×128）、N_p 的大小与分布（QPN，逐帧数据相关detectors/lmscnet.py:304-305）、采样偏移与权重（DCA 3 层＋DSA 2 层）、mask token、两侧主干。四家中 VoxFormer 独有：稀疏化本身是可学习的（LSS 稠密 splat、BEVFormer/TPVFormer 全网格 query）。
  • query 有无及形态：有，全网格表＋逐帧稀疏激活。N_q=262,144 条 3D 网格形可学习参数（论文 §3.3 "3D-grid-shaped learnable parameters"dense_heads/voxformer_head.py:53），每帧仅 N_p（QPN 输出，数据相关）参与 DCA——论文 Table 4（p.8）：100% dense 消融 IoU 34.6 vs occupancy 44.0、显存 18.5 G vs 14.6 G，稀疏既省显存又涨点；stage-2 用 mask token 把其余 voxel 补齐后经 DSA 稠密化（MAE 式 sparse-to-dense，论文 Fig.2 "Mask Token"＋"Updated Queries"dense_heads/voxformer_head.py:110-113）。对比：BEVFormer 40000 条 BEV 网格全激活、TPVFormer 46400 条三平面全激活、LSS 无 query。
  • 体间交互（BEVFormer 没有的）。DSA 是 voxel↔voxel 的 deformable 自注意力（3D 侧自注意力，论文 Eq.5；vanilla 实现在 512×512 展平索引面上采样，见 ④ 差异②modules/encoder.py:189-195）；BEVFormer 的 self-attn 在 BEV 平面＋时序，TPVFormer 的在平面间（CVHA）。VoxFormer 无时序 self-attn——T 变体的时序＝把历史帧当"更多相机"进 DCA（_temporal_=[-12,-9,-6,-3]、num_cams=5voxformer-T.py:18-19）。
